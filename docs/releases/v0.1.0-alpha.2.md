## 中文

### 新增

- 新增树级可用预算、超额责任统计和预算超限事件。

### 修改

- 明确 processed 仅表示消息消费成功，不代表委派任务完成。

### 修复

- 修复历史超限消息可能阻塞后续队列的问题，保留 rejected 状态与投递失败原因。
- 拒绝格式不正确的 Unicode 输入，避免已接收消息在 SQLite 中出现替换字符。

## English

### Added

- Added tree-level available-budget and excess-liability accounting, with budget-overrun events.

### Changed

- Clarified that processed confirms message consumption, not completion of delegated work.

### Fixed

- Fixed queue blocking by oversized historical messages; rejected messages retain their delivery-failure reasons.
- Rejected malformed Unicode input to prevent replacement characters in accepted messages stored in SQLite.
