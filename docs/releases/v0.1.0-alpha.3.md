## 中文

### 新增

- 新增持久任务板，支持显式完成、依赖关系、所有者、版本检查和幂等操作键。
- 新增 agent_task_create/get/list/update 工具及对应 CLI 命令。
- 新增紧凑团队视图 view 和事件等待 wait，支持持久游标、超时、取消和无进展原因。
- 新增英文 README 和中英文文档导航。

### 修改

- 业务数据库升级至 schema 5，加入任务、依赖、写入范围和任务请求记录。

## English

### Added

- Added a persistent task board with explicit completion, dependencies, ownership, revision checks, and idempotency keys.
- Added agent_task_create/get/list/update tools and corresponding CLI commands.
- Added the compact team view and event waiting with persistent cursors, timeouts, cancellation, and no-progress reasons.
- Added an English README and navigation between Chinese and English documentation.

### Changed

- Updated the business database to schema 5 with task, dependency, write-scope, and task-request records.
