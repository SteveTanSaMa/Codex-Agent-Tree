## 中文

### 新增

- 新增多仓库授权与独立 worktree 组，支持按仓库选择文件、搜索、diff、测试和 Lead 终端操作。
- 新增显式外部只读资源登记，供受限成员浏览和读取。
- 新增执行中引导、立即暂停、人工 check-in，以及连续自主执行、停滞和重复错误提示。
- 新增按成员或全树的单次、增量 token 提醒，可选择总量、非缓存输入或输出指标。
- 新增可审计的既有团队成员上限调整，保留成员身份和累计计数。

### 修改

- 新团队默认使用交互模式，取消累计 Turn 硬上限并保留统计；批处理模式和显式上限继续可用。
- 取消新团队的每对话 token 配额，默认全树达到 500 万总 token 提醒一次；累计成员默认上限改为 20。
- 数据库迁移至 schema 12，保存交互策略、提醒和多仓库状态；既有团队保留原策略与绑定。
- 优化 Task Board 的依赖和写入范围投影，减少重复扫描。

### 修复

- 修复引导投递、暂停和重启对账边界中的状态处理，保留不确定结果而不自动重放。
- 修复非主仓库操作的工作区锁与授权边界，并补充未完成 worktree 的恢复诊断。
- 修复 root 参数校验中无效 token 策略、已停用 enforce 和非法 Turn 上限的诊断区分。

## English

### Added

- Added multi-repository authorization and isolated worktree groups, with repository-specific file, search, diff, test and Lead terminal operations.
- Added explicit external read-only resources for restricted members to browse and read.
- Added live guidance, immediate pause, operator check-in, and warnings for continuous autonomy, stalls and repeated errors.
- Added per-Agent or tree-wide one-time and incremental token reminders, using total, uncached input or output metrics.
- Added audited lifetime member-limit changes for existing teams while preserving identities and retained counts.

### Changed

- New teams default to interactive mode with unlimited lifetime Turns and retained statistics; batch mode and explicit ceilings remain available.
- Removed per-conversation token allocations for new teams, defaulted to a one-time tree reminder at 5 million total tokens, and raised the default lifetime member ceiling to 20.
- Migrated the database to schema 12 for interaction, reminder and multi-repository state; existing teams retain their policies and bindings.
- Optimized Task Board dependency and write-scope projections to reduce repeated scans.

### Fixed

- Fixed state handling around guidance delivery, pause and restart reconciliation, retaining uncertain outcomes without automatic replay.
- Fixed workspace locking and authorization boundaries for non-primary repositories, and improved incomplete-worktree recovery diagnostics.
- Fixed root validation diagnostics to distinguish invalid token policies, retired enforce settings and invalid Turn ceilings.
