## 中文

### 新增

- 新增整棵树的累计 Turn 上限 --max-total-turns，与深度、累计 Agent 数、并发和单 Agent Turn 上限共同执行。

### 修改

- 新团队默认使用 tokenPolicy=observe；--tokens 改为用量告警阈值，子 Agent 的 token 分配变为可选。
- 保留 --token-policy enforce 的预算准入模式，已有团队保持原策略。
- status 和 view 增加 token 策略、用量告警及执行限额信息。
- 业务数据库升级至 schema 6，持久保存 token 策略和累计执行限额。

## English

### Added

- Added the lifetime tree Turn limit --max-total-turns alongside depth, lifetime Agent count, concurrency, and per-Agent Turn limits.

### Changed

- Changed new teams to tokenPolicy=observe by default; --tokens sets a usage-warning threshold and child token allocation is optional.
- Retained budget admission through --token-policy enforce; existing teams keep their prior policy.
- Extended status and view with token policy, usage warnings, and execution limits.
- Updated the business database to schema 6 to persist token policy and lifetime execution limits.
