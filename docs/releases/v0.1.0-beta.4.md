## 中文

### 修改

- 完成任务自动归档并释放活跃容量；新增分页历史查询和审计导出，迁移至 schema 15，保留已有回执和依赖。
- 新增环境预检、只读异常诊断、容量告警和升级备份与校验。
- 新增持久交接、可校验的 Git bundle、只读整合预览和显式整合回执。
- 新建 Lead Thread 支持受控后台命令的启动、状态查询和停止，最长运行 10 分钟。
- 命名测试可显式授权固定本地 TCP 端点，并可登记只读 SDK 和工具链资源。

### 修复

- 修复早到工具请求与 `turn/start` ACK 绑定竞态，并保留丢失 ACK 时的保守恢复。
- 修复并发停止可能在清理结束前返回，以及后台命令结算后任务替换可能停留在 `draining` 的问题。
- 修复后台命令独立运行时未计入活跃工作，导致自主执行提醒及时间预算可能失效的问题。
- 修复不完整 worktree 诊断漏项，区分整合预览失败与真实冲突，保留提交式交接成果以防 Git GC 丢失。
- 修复 Skill 包装器命令路由和环境诊断文档遗漏，优化活跃调度、任务投影及深依赖链的历史读取。

## English

### Changes

- Automatically archive completed tasks and release active capacity; add paged history and audit export, and migrate to schema 15 while preserving existing receipts and dependencies.
- Add environment preflight, read-only diagnostics, capacity warnings, and verified upgrade backups.
- Add durable handoffs, verifiable Git bundles, read-only integration previews, and explicit integration receipts.
- Allow new Lead Threads to start, inspect, and stop controlled background commands with a 10-minute maximum.
- Allow explicit fixed loopback TCP endpoints for named tests and registration of read-only SDK and toolchain resources.

### Fixes

- Fix the race between early tool requests and `turn/start` ACK binding while retaining conservative recovery after a lost ACK.
- Fix concurrent shutdown returning before cleanup completes and scope replacement remaining in `draining` after a background command settles.
- Fix running background commands being omitted from active-work accounting, which could suppress autonomy reminders and time-budget enforcement.
- Fix incomplete-worktree diagnostic gaps, distinguish integration-preview failures from actual conflicts, and retain committed handoffs against Git GC.
- Fix missing Skill wrapper routes and environment documentation; optimize historical reads in active scheduling, task projections, and deep dependency chains.
