# v0.1.0-beta.4 — candidate / 候选

## 修改 / Changes

- 完成任务自动归档并释放活跃容量；新增分页历史查询，迁移到 schema 15，保留旧回执与依赖。 / Automatically archive completed tasks and release active capacity; add paged history and schema 15 migration preserving receipts and dependencies.
- 新增只读异常诊断、持久交接记录和只读整合预览。 / Add read-only recovery diagnosis, persistent handoff records and integration previews.
- 命名测试支持显式固定本地 TCP 端口授权，复用 SDK 只读资源配置。 / Support explicitly configured fixed loopback TCP ports for named tests and existing read-only SDK resources.

- 增加可校验 Git bundle 保留、显式整合回执、容量告警、分页审计导出和升级预检/备份。 / Add verifiable Git bundle retention, explicit integration receipts, capacity warnings, paged audit export and upgrade preflight/backup.

- 修复 Skill 包装器遗漏命令路由及深依赖链重复扫描。 / Fix missing Skill command routes and repeated scans in deep dependency chains.
