## 中文

### 新增

- 新增操作者子树工作范围替换，持久记录工作代际、撤销收据和排空进度。
- 新增未知命令结果的人工核查结算入口，保留不确定结果并禁止自动重放。
- 新增持久 Runtime 环境与协议能力审计记录。

### 修改

- 取消精确 Codex CLI 版本锁，改为检查必需协议能力、输入契约和原生状态；保留启动器与运行中 daemon 的一致性检查。
- 将数据库迁移至 schema 13，保留已有身份、计数、策略与工作树。
- 将模型工具状态输出升级至投影 v2，限制历史与结果预览，保留完整数量和截断标记。
- 将调度改为最多三个独立预检槽位，新到达任务可使用空闲槽位，同一成员的预检保持串行。

### 修复

- 修复旧工作范围的迟到工具调用与排队报告仍可能继续推进的问题。
- 修复慢 RPC 阻塞新到达任务直到整波结束的问题。
- 修复停止期间迟到的预检结果仍进入 Turn 准备流程的问题。

## English

### Added

- Added operator-controlled subtree scope replacement with durable work generations, withdrawal receipts and draining progress.
- Added operator review settlement for unknown command outcomes, retaining uncertainty and disallowing automatic replay.
- Added persistent Runtime environment and protocol-capability audit records.

### Changed

- Replaced the exact Codex CLI pin with required capability, input-contract and native-state checks, retaining launcher/active-daemon consistency checks.
- Migrated the database to schema 13 while preserving existing identities, counters, policies and worktrees.
- Updated managed tool status to projection v2 with bounded history and result previews, full counts and truncation markers.
- Changed scheduling to at most three independent preflight slots, allowing new arrivals to use free slots while serializing each member's preflights.

### Fixed

- Fixed late tool calls and queued reports continuing work from withdrawn scopes.
- Fixed slow RPCs blocking newly arriving work until an entire scheduling wave completed.
- Fixed late preflight results entering Turn preparation during shutdown.
