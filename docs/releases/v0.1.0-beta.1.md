## 中文

### 新增

- 新增显式 Git 编码工作区：Lead 使用宿主终端，二级 Agent 在独立工作树中读写，三级及更深节点只读。
- 新增 read_file、write_file、search_code、git_diff 和白名单 run_test 工具，并按层级检查权限。
- 新增哈希校验的原子文件写入、路径与链接检查，以及受沙箱约束的命令和 Git 操作。
- 新增持久命令收据、输出与超时限制、取消处理和父进程退出清理。
- 新增隔离第三方模型配置，以及显式环境变量或 Keychain 凭据接入。

### 修改

- 人工消息和 Agent 消息统一使用持久 FIFO 入队顺序。
- 业务数据库升级至 schema 8；晚到的人工用量回执可保留为 pending，并在证据兼容后自动应用。

### 修复

- 修复人工用量回执与原生累计样本重叠时可能重复计数的问题。
- 修复原生 Turn 归属认领与迟到通知处理中的边界问题。
- 修复控制通道分块传输时的 UTF-8 解码问题。

## English

### Added

- Added opt-in Git coding workspaces: Lead uses a host terminal, second-level Agents write isolated worktrees, and deeper Agents have read-only access.
- Added read_file, write_file, search_code, git_diff, and allowlisted run_test tools with level-based authorization.
- Added hash-checked atomic file writes, path and link checks, and sandboxed command and Git operations.
- Added persistent command receipts, output and timeout limits, cancellation handling, and parent-death cleanup.
- Added isolated third-party model configuration and explicit environment-variable or Keychain credentials.

### Changed

- Unified human and Agent messages under a durable FIFO enqueue order.
- Updated the business database to schema 8; late operator usage receipts can remain pending and apply automatically when evidence becomes compatible.

### Fixed

- Fixed double counting when operator usage receipts overlap native cumulative samples.
- Fixed edge cases in native Turn ownership adoption and delayed-notification handling.
- Fixed UTF-8 decoding across control-channel chunks.
