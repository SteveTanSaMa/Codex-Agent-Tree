## 中文

### 新增

- 提供可安装的 Codex Skill，以及环境检查和依赖安装入口。
- 支持递归创建独立 Codex Session，并持久保存 Agent 身份与会话绑定。
- 支持持久消息、空闲节点唤醒，以及调用 CLI 退出后的后台运行。
- 加入 token 预算准入、生命周期控制和恢复对账。

## English

### Added

- Added an installable Codex Skill with environment checks and dependency setup.
- Added recursive creation of independent Codex sessions with persistent Agent identities and session bindings.
- Added persistent messaging, idle-agent wakeups, and background execution after the invoking CLI exits.
- Added token-budget admission, lifecycle controls, and recovery reconciliation.
