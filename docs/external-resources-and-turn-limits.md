# External resources and explicit Turn-limit changes

Current main adds operator-selected, team-wide external read-only resources to the immutable workspace manifest. These are distinct from writable repositories and per-Agent repository grants. Resources must be specific canonical files/directories outside all repositories, state and runtime home. Resource tools perform bounded text/binary reads and directory paging without execution. Lead commands and approved tests receive read access with explicit Seatbelt write denials. Existing native tool catalogs are preserved; new tools apply to new Threads.

`read_resource` reads at most 65536 bytes and hashes only that chunk; `list_resource` returns at most 1000 entries per page. Parent paths, protected entries, symlink traversal, unknown resource IDs and changed resource-root symlinks fail closed. Resource paths are revalidated before commands. This remains a trusted-local-workspace policy, not a claim against malicious host processes, hardlink aliases or every filesystem race. See [coding operations](../references/coding.md#external-read-only-resources).

Interactive Turn defaults are unlimited; batch keeps 20 per Agent and 100 per tree. See [interactive execution control](interactive-control.md). Explicit `unlimited` maps to persisted JSON null, distinct from an omitted default. Operator-only `limits` changes these two ceilings transactionally, preserving identities and counts and recording before/after/reason. Agent count, concurrency, depth, token policy and reconciliation fences remain unchanged. Offline updates require exclusive normal Store ownership and reject a live Coordinator. Schema 12 prevents older source from interpreting disabled per-Agent ceilings incorrectly. See [operations](../references/operations.md#explicit-turn-limit-changes).

Validation: current default suites pass 132 tests (8 unit + 124 integration), with 6 native tests skipped; fault suites pass 32 tests. Resource tests exercise actual Seatbelt read/write boundaries, binary chunks, path escapes and immutable registration. Turn-limit tests cover more than 100 retained executions, restart/binding retention, rejection below usage, and the public offline CLI's live-owner refusal. Interactive controls and reminders have additional bounded tests documented in their operation guides. Typecheck, Skill metadata, packaging and diff checks pass. Local workload evidence is excluded from distribution. No new Release is created by this main-branch update.
